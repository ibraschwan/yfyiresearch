# YFYİ — Yeni Fikirler Yeni İşler (ODTÜ TEKNOKENT) — Research Documentation

Research dossier on **YFYİ (Yeni Fikirler Yeni İşler / "New Ideas New Business")**, the
early-stage startup acceleration program run by **ODTÜ (Middle East Technical University)**
and **ODTÜ TEKNOKENT** since 2005.

Compiled: **19 August 2026**. All data is from public sources (see `08-sources.md`).

## Reading the confidence markers

Throughout the docs:

- **[C]** — Confirmed by an official/primary source (yfyi.com, odtuteknokent.com.tr,
  elginkanvakfi.org.tr, YFYİ's own LinkedIn, METU channels).
- **[R]** — Reported by credible trade press (Webrazzi, egirişim, Anadolu Ajansı, BTHaber).
- **[?]** — Uncertain, single-source, or sources disagree. See `09-data-gaps.md`.
